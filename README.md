# theoremsol.in — holding page

Single static page for Theorem Solutions, the legal entity behind Viveka. It shows the company
particulars and sends visitors to https://www.claritybyviveka.in/.

No build step: Vercel serves the files as they are (Framework preset: "Other").

- `index.html` — the page (copy, styles and Organization structured data in one file)
- `404.html` — any unknown address, pointing to claritybyviveka.in
- `vercel.json` — forwards the old /referable and /pitchframe addresses to claritybyviveka.in
- `theorem-logo-horizontal.png`, `icon.png`, `apple-touch-icon.png` — logo and icons
